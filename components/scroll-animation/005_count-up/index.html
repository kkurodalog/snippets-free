005_count-up

Intersection Observer でビューポートへの進入を検知し、 requestAnimationFrame で 0 から目標値まで数値を補間する カウントアップです。イージング（easeOutQuad）で最初は速く、 最後はゆっくり目標値へ着地します。各カウンターは一度発火したら監視を解除します。 OS の「視差効果を減らす」設定が有効な場合は、カウントせず即時に最終値を表示します。

下方向へスクロールすると、画面に入ったタイミングで数値が 0 から動き出します。実績やKPIをページ内で印象的に見せたいときに使えます。

  • 1,200+ 導入企業
  • 98% 満足度
  • 50,000 累計ダウンロード
  • 4.8 平均評価
