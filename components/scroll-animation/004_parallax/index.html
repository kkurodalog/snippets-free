004_parallax

背景レイヤーと前景コンテンツにスクロール速度の差を つけることで、奥行き（視差）を感じさせる実装です。対応ブラウザでは animation-timeline: view() によって、各レイヤーが ビューポートを通過する進捗に連動して動きます（JS なし・CSS だけ）。この機能に未対応のブラウザでは、scroll イベントと requestAnimationFrame を使った軽量な JS が 同じ translateY を計算してレイヤーを動かします （フォールバック）。OS の「視差効果を減らす」設定が有効な場合は、 視差を完全に無効化して通常の表示にします。下方向にスクロールして 奥行きを確認してください。

奥行きセクション 1

背景の図形が前景の見出しよりゆっくり動くことで、背景が「奥」に あるように感じられます。スクロールするほど、その速度差が 奥行きとして見えてきます。

奥行きセクション 2

背景のグラデーションと図形がスクロールに対してゆっくり追従します。 前景のテキストは通常の速度で流れるため、レイヤー間に視差が生まれます。

奥行きセクション 3

対応ブラウザではこの動きを CSS の animation-timeline: view() だけで 実現しています。未対応ブラウザでは軽量な JS が同じ translateY を 計算して背景を動かします。

ここがページの終端です。各セクションで、背景が前景より遅れて動いて いたことを確認できたでしょうか。十分なスクロール量を確保するために、 各セクションは縦に長く取っています。
