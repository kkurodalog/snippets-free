# Snippets Free

コピペして使えるフロントエンドのパーツ集。
HTML・CSS・JavaScript のパーツを、動くデモとコードで並べたカタログ。

- 公開URL: https://kkurodalog.github.io/snippets-free/
- ライセンス: MIT（**素材は対象外** / [LICENSE](LICENSE)）

---

## 掲載基準

載せているパーツは、次の4項目を確かめてから公開する。

- (1) **プログレッシブエンハンスメント** — JavaScript 無効・機能非対応の環境でも情報が欠けない
- (2) **動きの軽減に対応** — `prefers-reduced-motion: reduce` で意図どおり止まる
- (3) **キーボード操作** — 操作要素に到達でき、フォーカスが見える
- (4) **実挙動の実測** — 静的なレビューで終わらせず、実ブラウザで動きを計測する

満たしていない項目があるパーツは、その項目を明示する。
実現方法は [CODING-RULES.md](CODING-RULES.md) にまとめている。

## ディレクトリ構成

```
/
├── index.html            トップ（生成）
├── sitemap.xml           サイトマップ（生成）
├── assets/               カタログ外殻（手書き / そのまま配信）
│   ├── css/style.css     外殻のスタイル1本
│   ├── js/catalog.js     外殻のスクリプト（ES modules / バンドルしない）
│   ├── js/code-modal.js  コードモーダル（デモの実ファイルを読んで表示・コピー）
│   ├── js/code-highlight.js  コードの着色（外部ライブラリなし）
│   └── js/snippet-marker.js  掲載範囲マーカーの解釈（表示と検査で共有）
├── components/
│   └── {カテゴリ}/
│       ├── index.html    カテゴリ一覧（生成）
│       └── {NNN_slug}/   デモの実体（手書き / 素の HTML・CSS・JS）
├── utils/                旧構成のデモ（components/ へ移設予定）
├── media/                プレビュー素材（整備中）
├── site/                 生成の入力（データ・共通部分・ページ雛形）
└── tools/                生成スクリプトと検証スクリプト
```

「整備中」と書いた行は、まだ実体が無いか揃っていない。順に埋めていく。

- **デモの実体は1箇所だけ。** 生成で別の場所に複製しない。
  GitHub 上で見えるファイル・コピーされるファイル・編集するファイルが完全に一致する
- **生成物を手で編集しない。** 編集は `site/` 配下に対して行う

## セットアップと生成

Node.js があれば動く。**外部パッケージへの依存はゼロ**。

```bash
# 生成（トップとカテゴリ一覧を書き出す）
npm run build

# 日常の検証（相対パス / 配色・ブレークポイント / 内部リンクの実在 / 掲載範囲マーカー / 検証データ / 社内記法）
npm run check

# 公開ゲート（上の6本 ＋ 掲載範囲マーカーの未埋め込みと掲載基準の未実測を違反として扱う）
npm run check:release

# ローカル配信（公開時と同じ深さで確かめる）
npm run serve   # → http://127.0.0.1:8000/snippets-free/
```

**`npm run check` と `npm run check:release` の違い**

| コマンド | 何を見るか | いつ使うか |
|---|---|---|
| `npm run check` | 規約違反だけを違反として扱う。**掲載範囲マーカーの未埋め込みと掲載基準の未実測は警告**にとどめる | 日常。埋め込みや実測の最中に検査が常に赤いと、検査そのものを見なくなる |
| `npm run check:release` | `npm run check` と同じ6本に加え、**未埋め込みと未実測も違反**として扱う | 公開・マージの判定 |

⚠️ **未実測は警告どまりだが、「実測していないのに検証行を出す」は日常の検査でも違反**である。
モーダルの検証行は掲載基準4項目を満たしたと画面で述べる面であり、
述べる根拠は `site/data/verification-clearance.json` の記録にしか無い。
記録と食い違う値は `npm run build` が書き出しを拒む。

終了コードは 0 = 違反0件 / 1 = 違反あり / 2 = 走査対象が0件（未走査）。
`npm run check:release` は `npm run check` を呼んでから追加の判定を足す形にしてある。
**検査を1本増やすときは `npm run check` の側に足せば、公開ゲートにも自動で載る。**

⚠️ **`file://` で開くとコードモーダルが中身を読めない。** モーダルはコードの写しを持たず、
開いたときにデモの実ファイルを取得する。ローカルで確かめるときは必ずローカル配信で開くこと。

⚠️ **ルート直下で配信すると、公開時にだけ壊れるリンクを見逃す。**
公開URLは `/snippets-free/` 配下にあるため、**同じ深さのサブディレクトリに置いて配信する**。
`npm run serve` はそのための入れ物（`.serve/snippets-free` へのシンボリックリンク）を作ってから配信する。
手で組む場合は次のとおり。

```bash
mkdir -p /tmp/serve && ln -sfn "$PWD" /tmp/serve/snippets-free
cd /tmp/serve && python3 -m http.server 8000   # → http://127.0.0.1:8000/snippets-free/
```

## 触るときの約束

- **整形・lint・バンドル・画像最適化のツールを導入しない。**
  掲載しているコードが気づかないうちに書き換わる事故を、発生源から断つため
- **サイト内リンクに絶対パスを書かない。** 相対パスに統一する（`npm run check` が検出する）
- **生成スクリプトはデモを上書きできない。** 掲載物への書き込みはファイル名で制限してある
- **コピーできる範囲はマーカーで示す。** 記法と置き方は [CODING-RULES.md](CODING-RULES.md) の「掲載範囲マーカー」にまとめてある
- **カタログ側にコードの写しを持たない。** カード上のモーダルは開いたときにデモの実ファイルを読む。
  デモを直せば、コピーされるコードもその場で変わる
